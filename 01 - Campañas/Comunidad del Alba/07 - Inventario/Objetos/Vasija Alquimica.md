## ⚔️ Propiedades y Mecánicas (D&D 5e)
Esta vasija de cerámica pesada puede producir diferentes líquidos mágicos una vez por día según la orden que se le dé:

| Líquido | Cantidad Máxima Diaria |
| :--- | :--- |
| **Ácido** | 8 onzas (1 vial de ácido) |
| **Veneno Básico** | 1/2 onza (1 dosis de veneno) |
| **Cerveza** | 4 galones |
| **Vino** | 1 galón |
| **Aceite** | 1 cuarto de galón |
| **Miel** | 1 galón |
| **Mayonesa** | 2 galones |
| **Agua dulce** | 8 galones |
| **Agua salada** | 12 galones |
| **Vinagre** | 2 galones |

- **Uso:** Como acción, nombras el líquido deseado y viertes el contenido a través de su boquilla. Una vez que produce la cantidad máxima del líquido elegido, no puede producir más hasta el siguiente amanecer.
